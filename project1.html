The Alchemist's Brew

The Alchemist's Brew is a concept website for a fictional coffee shop that treats every drink as an experiment. It has six pages: Home, Story, Menu, Community, Visit, and a hidden secret page. It is built with plain HTML, CSS, and vanilla JavaScript, with no frameworks.

Interactive features include a daily guessing game, a filterable menu, a zoomable illustrated map, a guestbook wall, a suspended-coffee counter, and a contact form that confirms your message. The layout adapts from phone to desktop.

This is a concept project: the business is fictional, and the forms only show messages on the page and do not send data anywhere.

How it was made

I wrote the HTML, CSS, and JavaScript myself, and used an AI assistant to help review the code and fix bugs. All of the pictures on the site are AI-generated, and the home page hero image was generated from an Unsplash photo. The business is fictional.
